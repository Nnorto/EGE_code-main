Решение:
В данной задаче даны:
   1) Межотраслевые потоки – (x_ij)3x3
               ⎛ 65  35  0  ⎞
   (x_ij)3x3 = ⎜ 25  25  35 ⎟
               ⎝ 15  45  45 ⎠
   2) Вектор конечного продукта
       ⎛ 65 ⎞
   Y = ⎜ 65 ⎟
       ⎝ 75 ⎠
   3) Затраты живого труда в j –той отрасли x_j^t
   x1^t = 3300 (тыс. чел.)
   x2^t = 2550 (тыс. чел.)
   x3^t = 3600 (тыс. чел.)
   Вычислим коэффициенты прямых материальных затрат по формуле (8).
Для этого нам нужно знать вектор валового продукта по отраслям:
   x1 = Σ(j=1..n) x1j + y1 = 65 + 35 + 0 + 65 = 165
   x2 = Σ(j=1..n) x2j + y2 = 25 + 25 + 35 + 65 = 150
   x3 = Σ(j=1..n) x3j + y3 = 15 + 45 + 45 + 75 = 180
Тогда коэффициенты прямых материальных затрат равны:
   a11 = 65/165 = 0.393939    a12 = 35/150 = 0.233333    a13 = 0
   a21 = 25/165 = 0.151515    a22 = 25/150 = 0.166667    a23 = 35/180 = 0.194444
   a31 = 15/165 = 0.090909    a32 = 45/150 = 0.3    a33 = 45/180 = 0.25
               ⎛ 0.393939  0.233333  0        ⎞
   (a_ij)3x3 = ⎜ 0.151515  0.166667  0.194444 ⎟
               ⎝ 0.090909  0.3       0.25     ⎠
Вычислим сначала
           ⎛ 1  0  0 ⎞   ⎛ 0.393939  0.233333  0        ⎞
   E − A = ⎜ 0  1  0 ⎟ − ⎜ 0.151515  0.166667  0.194444 ⎟ =
           ⎝ 0  0  1 ⎠   ⎝ 0.090909  0.3       0.25     ⎠
     ⎛ 0.606061   -0.233333  0         ⎞
   = ⎜ -0.151515  0.833333   -0.194444 ⎟ .
     ⎝ -0.090909  -0.3       0.75      ⎠
   Далее вычислим алгебраические дополнения к элементам матрицы Е-А:

D11=(-1)^2·(0.833333·0.75 - (-0.194444)·(-0.3)) = 0.566667,
D12=(-1)^3·((-0.151515)·0.75 - (-0.194444)·(-0.090909)) = 0.131313,
D13=(-1)^4·((-0.151515)·(-0.3) - 0.833333·(-0.090909)) = 0.121212,
D21=(-1)^3·((-0.233333)·0.75 - 0·(-0.3)) = 0.175,
D22=(-1)^4·(0.606061·0.75 - 0·(-0.090909)) = 0.454545,
D23=(-1)^5·(0.606061·(-0.3) - (-0.233333)·(-0.090909)) = 0.20303,
D31=(-1)^4·((-0.233333)·(-0.194444) - 0·0.833333) = 0.04537,
D32=(-1)^5·(0.606061·(-0.194444) - 0·(-0.151515)) = 0.117845,
D33=(-1)^6·(0.606061·0.833333 - (-0.233333)·(-0.151515)) = 0.469697,
Определитель матрицы равен:
 det(E-A) = 0.606061·0.833333·0.75 + (-0.233333)·(-0.194444)·(-0.090909) + (-0.151515)·(-0.3)·0 -
 - 0·0.833333·(-0.090909) - (-0.233333)·(-0.151515)·0.75 - (-0.194444)·(-0.3)·0.606061 = 0.312795.

Тогда обратная матрица может быть вычислена по формуле (12):
                           ⎛ 0.566667  0.131313  0.121212 ⎞
   (E-A)^-1 = 1/0.312795 · ⎜ 0.175     0.454545  0.20303  ⎟ ^T =
                           ⎝ 0.04537   0.117845  0.469697 ⎠
                  ⎛ 0.566667  0.175     0.04537  ⎞
   = 1/0.312795 · ⎜ 0.131313  0.454545  0.117845 ⎟ .
                  ⎝ 0.121212  0.20303   0.469697 ⎠
После соответствующих вычислений, получаем матрицу (Е-А)^-1:
              ⎛ 1.811625  0.559473  0.145048 ⎞
   (E-A)^-1 = ⎜ 0.419806  1.453175  0.376749 ⎟ .
              ⎝ 0.387513  0.649085  1.501615 ⎠
   Матрица коэффициентов полных материальных затрат может быть
вычислена по формуле (11). Итак, матрица полных материальных затрат равна:
                         С=(Е-А)^-1 - Е.
                    ⎛ 1.811625  0.559473  0.145048 ⎞   ⎛ 1  0  0 ⎞
   C=(E-A)^-1 − E = ⎜ 0.419806  1.453175  0.376749 ⎟ − ⎜ 0  1  0 ⎟ =
                    ⎝ 0.387513  0.649085  1.501615 ⎠   ⎝ 0  0  1 ⎠
     ⎛ 0.811625  0.559473  0.145048 ⎞
   = ⎜ 0.419806  0.453175  0.376749 ⎟ .
     ⎝ 0.387513  0.649085  0.501615 ⎠
   Коэффициенты косвенных материальных затрат 1-го порядка могут
быть вычислены по формуле:
        a_ij^(1) = a_i1·a_1j + a_i2·a_2j + ... + a_in·a_nj ,
                                       ⎛ 0.190542  0.130808  0.04537  ⎞
   A^(1) = (a_ij^(1))nxn = A^2 = A×A = ⎜ 0.102617  0.121465  0.081019 ⎟ .
                                       ⎝ 0.103994  0.146212  0.120833 ⎠
   Коэффициенты прямых затрат труда на единицу продукции j-той от-
расли определяются по формуле (9):
   t1 = x1^t / x1 = 3300 тыс. чел. / 165 млрд. руб. = 20 тыс. чел./млрд. руб.,
   t2 = x2^t / x2 = 2550 тыс. чел. / 150 млрд. руб. = 17 тыс. чел./млрд. руб.,
   t3 = x3^t / x3 = 3600 тыс. чел. / 180 млрд. руб. = 20 тыс. чел./млрд. руб.
По формуле (11) найдем коэффициенты полной трудоемкости Т:
                                     ⎛ 1.811625  0.559473  0.145048 ⎞
   T = t·(E-A)^-1 = ( 20  17  20 ) · ⎜ 0.419806  1.453175  0.376749 ⎟ =
                                     ⎝ 0.387513  0.649085  1.501615 ⎠
   = (51.119483, 48.875135, 39.337998).
Определим величину изменения валового выпуска продукции отрас-
лей
                        ⎛ 1.811625  0.559473  0.145048 ⎞   ⎛ 26  ⎞   ⎛ 55.090285 ⎞
   ∆x = (E-A)^-1 · ∆y = ⎜ 0.419806  1.453175  0.376749 ⎟ · ⎜ 6.5 ⎟ = ⎜ 31.663079 ⎟ .
                        ⎝ 0.387513  0.649085  1.501615 ⎠   ⎝ 30  ⎠   ⎝ 59.342842 ⎠
Дополнительную потребность в трудовых ресурсах определим следу-
ющим образом:
   ∆x1^t = t1·∆x1 ,  ∆x1^t = 20 тыс. чел./млрд. руб. · 55.090285 млрд. руб. = 1101.805705 тыс. чел.
   ∆x2^t = t2·∆x2 ,  ∆x2^t = 17 тыс. чел./млрд. руб. · 31.663079 млрд. руб. = 538.272336 тыс. чел.
   ∆x3^t = t3·∆x3 ,  ∆x3^t = 20 тыс. чел./млрд. руб. · 59.342842 млрд. руб. = 1186.856835 тыс. чел.
Вычислим коэффициенты прямой и полной фондоемкости:
   f1 = Ф1 / x1 = 100 млрд. руб. / 165 млрд. руб. = 0.606061,
   f2 = Ф2 / x2 = 120 млрд. руб. / 150 млрд. руб. = 0.8,
   f3 = Ф3 / x3 = 150 млрд. руб. / 180 млрд. руб. = 0.833333.
                                                  ⎛ 1.811625  0.559473  0.145048 ⎞
   F = f·(E-A)^-1 = ( 0.606061  0.8  0.833333 ) · ⎜ 0.419806  1.453175  0.376749 ⎟ =
                                                  ⎝ 0.387513  0.649085  1.501615 ⎠
   = (1.756728, 2.042519, 1.640653).
Наконец, вычислим дополнительную потребность в основных произ-
водственных фондах:
   ∆Ф1 = f1·∆x1 ,  ∆Ф1 = 0.606061 · 55.090285 млрд. руб. = 33.388052 млрд. руб.
   ∆Ф2 = f2·∆x2 ,  ∆Ф2 = 0.8 · 31.663079 млрд. руб. = 25.330463 млрд. руб.
   ∆Ф3 = f3·∆x3 ,  ∆Ф3 = 0.833333 · 59.342842 млрд. руб. = 49.452368 млрд. руб.
